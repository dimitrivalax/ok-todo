## Description

```
Ok! Todo is a simple, open-source todo list designed to stay on your iPhone — and nowhere else.

No account. No cloud. No ads. No tracking.
Your tasks stay on your device only.

WHY OK! TODO?

A todo list without the clutter: write what you need to do, check it off, move on. The app organizes your tasks automatically based on the time of day.

• Today — tasks still ahead for today
• Tomorrow — tasks whose time has already passed
• One day — tasks with no set time

FEATURES

• Clean, lightweight task list
• Optional due time for each task
• Local reminders at the time you choose
• Daily “plan your day” reminder (configurable time)
• Works offline, always
• UI available in 24 European languages
• No sign-up, no cloud sync
• Open source — free and auditable code

PRIVACY & OPEN SOURCE

Ok! Todo collects no personal data.
No analytics, no ads, no user account.
What you write stays with you.

The project is free and open source under the GNU GPL v3: the source code is public, transparent, and reusable.

Ideal if you want an efficient, discreet, open-source todo list that respects your privacy — with nothing superfluous.
```
